# 3단계: 수동 수정

## 저장 구조 (project.json 버전 3)
- `auto`: 자동 분석 결과. 사람이 고쳐도 바뀌지 않음
- `tracks`: 편집용 트랙. 자동 결과를 가리키고(`auto`, `span`) 그 위에 수정을 얹음
  - `keys`: 사람이 고친 프레임의 상자 `{프레임: [x1, y1, x2, y2]}`
  - `removed`: 지운 구간 `[[시작, 끝), ...]`
- 실제로 가릴 상자는 `Project.track_boxes()`가 계산
- 버전 2 파일은 열 때 자동으로 옮김 (수정 없는 상태)

## 키프레임 보간
- 자동 상자가 있는 구간: 고친 차이(위치·크기 보정)를 키프레임 사이에 이어서 적용 → 자동 추적의 움직임은 그대로 살림
- 자동 상자가 없는 구간(직접 그린 상자): 키프레임 사이를 직선으로 이음
- 첫·마지막 키프레임 바깥은 보정을 0.5초 동안 서서히 없앰 (튀지 않게)

## 화면
- `B` 상자 편집: 상자 클릭=선택, 끌기=이동, 모서리=크기, 빈 곳 끌기=새 상자(선택한 직접 그린 상자가 있으면 이어 그리기)
- 화면에 보이는 상자는 실제로 가려지는 영역 (얼굴 상자를 이마·턱까지 넓힌 것). 저장할 때 다시 얼굴 상자로 바꿈
- 선택한 상자: 이 프레임만 / 시작~끝 구간 / 전부 지우기(⌫), 여기부터 다른 사람(S), 인물 바꾸기, 손댄 것 되돌리기
- 인물 목록: ⌘-클릭으로 여러 명 골라 합치기, 인물 삭제(얼굴 아님)
- `⌘Z` / `⇧⌘Z`: 실행 취소 / 다시 실행 (효과·이름·구간 변경도 포함, 최대 200번)
- 타임라인 아래 주황 ▲ = 확인이 필요한 곳 (오래 이어 붙인 구간, 점수 낮은 구간, 확인 필요 인물). `N`으로 다음 위치 이동
