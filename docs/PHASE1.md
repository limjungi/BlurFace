## 0단계 문제 해결
| 문제 | 결과 |
|---|---|
| 컷 오검출 (4K 21개) | 자체 컷 감지로 5개, 실제 컷 8/8 정확 (두 영상 합계), 오검출 0 |
| 영상 두 번 읽음 | 디코딩 한 번에 컷·검출·특징값 처리 |
| 재등장 인물이 새 번호 | ArcFace 군집화로 연결 (같은 사람 유사도 0.58~0.89, 다른 사람 ≤0.08) |
| 모자이크 약함 | 블록 수 조절 가능 (기본 8) |

## 추가로 한 것
- 인물별 효과 (모자이크, 블러, 단색, 스티커 2종, 사용자 PNG, 없음), 프로젝트에 저장
- 세로 영상 회전, 10bit HDR 유지, 색 정보(primaries/trc/colorspace) 유지, 오디오 원본 복사
- 원본 대비 화질: 효과 없을 때 PSNR 55dB (사실상 동일)
- 블러 속도 개선 (줄여서 흐린 뒤 키움, 내보내기 19.6s → 6.8s)
- 점수가 낮거나 0.5초 미만 등장한 인물에 "확인 필요" 표시

## 남은 문제
- 손·뒤통수 오검출 (4K 광고의 피자 만드는 장면) → "확인 필요"로 표시, `--person N=none`으로 끌 수 있음
- 같은 사람이 조명·각도 차이로 둘로 나뉘는 경우 있음 → 3단계 인물 합치기
- 화면 가장자리에 걸친 얼굴 누락 → 3단계 수동 수정
