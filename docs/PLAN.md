# BlurFace 개발 계획

## 목적
완성된 영상(FHD 위주, 최대 4K)에서 얼굴을 자동 추적해 가린 모자이크 버전을 만드는 macOS 전용 개인용 앱. 실시간 처리 없음.

## 스택
| 영역 | 선택 |
|---|---|
| 앱 | Python 3.12 + PySide6 (macOS `.app`) |
| 영상 입출력 | PyAV + FFmpeg (VideoToolbox 인코딩, 오디오 copy, 10bit/색공간 보존) |
| 얼굴 검출 | SCRFD-10G 또는 Apple Vision (0단계 실측으로 결정) |
| 컷 감지 / 추적 | PySceneDetect / ByteTrack (supervision) |
| 인물 구분 | ArcFace 임베딩 → 군집화 |
| 추론 | ONNX Runtime + CoreML EP |
| 효과 | OpenCV + NumPy |
| 환경 | uv |

## 설계 원칙
- 자동 분석 결과와 수동 수정 내역을 분리 저장 (재분석해도 수정 유지)
- 데이터는 타임스탬프(PTS) 기준 (가변 프레임레이트 대응)
- 4K는 분석만 축소 해상도, 출력은 원본 해상도

## 단계 (약 7주)
| 단계 | 기간 | 산출물 |
|---|---|---|
| 0. 기술 검증 | 1주 | 검출기 비교(SCRFD vs Vision), 컷 감지·추적 시험, 속도 측정 |
| 1. 엔진 + CLI | 2주 | `blurface run 입력.mp4` → 모자이크 영상 (실사용 가능) |
| 2. 기본 화면 | 2주 | 불러오기, 진행률, 미리보기, 인물 목록, 인물별 효과, 내보내기 |
| 3. 수동 수정 | 2주 | 상자 편집, 키프레임 보간, 트랙 합치기·나누기, 실행 취소, 검토 구간 표시 |

## 범위 밖
실시간 처리, Windows, 영상 편집 기능, 얼굴 외 대상, 배포용 설치 파일.
