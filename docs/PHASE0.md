# 0단계 기술 검증 결과 (2026-11-17, M1 계열 Mac)

## 검출기 비교 (0.5초 간격 샘플, 분석 해상도 1920)
| 검출기 | ms/프레임 | 판단 |
|---|---|---|
| **SCRFD-640 + CoreML** | **12** | 채택. 어두운 페이드 장면도 검출, 오검출 없음 |
| SCRFD-640 CPU | 160 | CoreML 대비 13배 느림 |
| SCRFD-1280 + CoreML | 37 | 640 대비 이득 없음 |
| YuNet | 22 | 정장을 얼굴로 오검출 |
| Apple Vision | 11~14 | 상자가 작아 이마가 빠짐, 어두운 장면 놓침 |

CoreML은 입력 크기를 고정한 모델이어야 동작함 (`fixed_size_model`).

## 발견한 문제 → 다음 단계
- 컷 오검출: 빠른 움직임을 컷으로 잡음 → 감지 기준 조정 또는 자체 구현 (1단계)
- 컷 감지가 영상을 한 번 더 읽음 → 검출과 같은 디코딩에서 처리 (1단계)
- 다음 장면에 다시 나온 같은 사람이 새 번호로 잡힘 → ArcFace 인물 구분 (1단계)
- 화면 가장자리에 걸친 얼굴, 고개 돌린 얼굴 일부 놓침 → 수동 수정 (3단계), 기준값 조정
- OpenCV와 PyAV의 FFmpeg 라이브러리 중복 경고 → 현재 문제 없음, 계속 관찰
