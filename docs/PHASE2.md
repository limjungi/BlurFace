# 2단계 화면 결과 (2026-11-17)

`uv run blurface gui [영상]`

## 화면
- 왼쪽: 인물 목록 (대표 얼굴, 현재 효과, 구간 수, ⚠ 확인 필요), 맨 위 "모든 인물 기본 효과"
- 가운데: 효과가 적용된 미리보기, 재생, 타임라인 (컷, 선택 인물 등장 구간, 구간 효과, 시작/끝 표시)
- 오른쪽: 인물 이름·효과, 구간 효과 (I/O로 시작/끝 → 효과 선택 → 추가, 더블클릭으로 이동)
- 위: 열기(⌘O, 끌어다 놓기), 다시 분석, 내보내기(⌘E), 상자 표시(B)

## 구간 효과
같은 인물도 시간 구간마다 다른 효과. 겹치면 나중에 추가한 구간이 우선. CLI: `--person-at 0@12-20=sticker:heart`

## 확인한 것
- 미리보기 프레임 이동 정확도: 무작위 이동 100회 모두 순차 재생과 동일 (FHD·4K·HDR)
- 재생: 순차 디코딩 4K도 7ms/프레임 → 실시간
- 분석·내보내기는 별도 스레드, 진행률·남은 시간·취소
- 사용자 이미지는 프로젝트 폴더로 복사 (원본을 옮겨도 유지)

## 알려진 한계
- 4K 영상에서 먼 곳으로 이동할 때 0.5초 정도 걸림 (키프레임 간격이 긴 YouTube 영상 기준)
- 분석 시작 후 약 5초는 얼굴 인식 모델 준비 시간
